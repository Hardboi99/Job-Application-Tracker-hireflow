# HireFlow

A WordPress plugin and theme ecosystem for tracking job applications. Started this project to have a clean way to track my own job hunt.

## Quick Start

1. Install/activate the `hireflow-manager` plugin.
2. Install/activate the `hireflow-theme`.
3. Create a page with the "HireFlow Dashboard" template.

## Requirements

- WP 6.0+
- PHP 8.0+

## Structure

```
hireflow/

│   ├── admin/

└── hireflow-theme/ (Theme)

    ├── index.php
    └── style.css
```
